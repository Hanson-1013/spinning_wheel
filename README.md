# Three.js 实验室

## 实验 001：流形 / Particle Atrium

参考暗色建筑空间中的发光粒子装置，当前为程序化场景与交互原型，没有使用原图的建筑资产。使用 Three.js WebGL + 自定义 GLSL 粒子材质，尚未使用 TSL / WebGPU。

启动：`npm install`，然后 `npm run dev`，打开终端显示的本地地址。构建：`npm run build`。

- 鼠标移动或触屏拖动：排斥附近粒子；移开后弹簧阻尼回归。
- 点击：增强一次局部扩散。右侧可调回归力度、阻尼、作用范围。
- 暂停流动会冻结模拟，重置恢复默认参数和粒子位置。
- 12,000 个粒子，CPU 固定上限时间步与两次子步积分；帧率视设备而定。
- 需要 WebGL2；依赖通过 npm 安装。本地渲染不调用任何模型服务。

## 实验 002：水上纺车

按用户录屏搭建程序化木制纺车：大轮、辐条、传动带、线轴、踏板。拖模型移动；点击“操作：移动”切到旋转后左右拖动；可停止转轮、模型归位。粒子默认隐藏，可用按钮显示。水面细雨保留。参考建模不等同于视频精确复刻，未使用视频中的游戏资产。

当前交互：纺车位置固定，纺轮约四分之三高度露出水面。在画面空白处按住并左右拉动即可带动轮子，松手惯性衰减。旧版拖动模型/旋转视角操作已取消；使用“停止惯性”和“转轮复位”控制轮子。

## 当前：一圈织光

左右拖动画面，累计约720像素完成一次拉动，可分段接续。轮子前快后慢、逐渐增阻，终点精确一圈。四周白色粒子随进度汇聚变金，形成越来越亮的光球；完成时全屏暖金泛白，随后光球消散。点击“重新织光”恢复起点。“停在此刻”暂停轮子追随，继续拖动可接续。旧版无限转动与粒子形态切换已被本演出取代。

终点演出更新：光球形成后持续5.5秒膨胀至满屏，光晕同步从中心向外扩张；保持后在第7—10秒缓慢淡出，替代旧版瞬时泛白。
